## 📚 Sobre a Plataforma

**EduMoz** é uma plataforma de educação online criada para estudantes da **1ª à 12ª classe em Moçambique**, com o objetivo de tornar o aprendizado mais acessível, moderno, interativo e eficiente.

A plataforma oferece conteúdos alinhados ao currículo nacional, exercícios interativos, acompanhamento de desempenho e ferramentas para conectar alunos, pais e professores em um único ambiente digital.

---

# 🎯 Objetivos da Plataforma

A EduMoz foi desenvolvida para:

- Melhorar o desempenho académico dos estudantes
- Oferecer conteúdos interativos e alinhados ao currículo nacional
- Fornecer feedback automático e relatórios detalhados
- Criar uma comunidade de aprendizado entre alunos, pais e professores
- Incentivar o aprendizado contínuo através da gamificação

# Historico de Desenvolvimento

## 2026-05-24 - Estrutura inicial da plataforma

Foi criada a primeira estrutura base dentro de `src`, usando a versao menor
planeada para iniciar o desenvolvimento da EduMoz passo a passo.

Estrutura criada:

- `src/components/layout` para elementos fixos como header e footer
- `src/components/home` para secoes da pagina inicial
- `src/components/ui` para componentes reutilizaveis
- `src/routes` para paginas publicas e primeira area do aluno
- `src/data` para dados temporarios antes da base de dados
- `src/types` para contratos TypeScript da plataforma
- `src/lib` para constantes e utilitarios partilhados

Tambem foram criadas as primeiras paginas:

- `/`
- `/aluno`
- `/entrar`
- `/solicitar-acesso`

Observacao: a pagina inicial foi ligada aos primeiros componentes da EduMoz e
o idioma base do documento foi ajustado para `pt-MZ`.

## 2026-05-24 - Tailwind CSS como padrao visual

Foi definido que o estilo da plataforma EduMoz sera construido com Tailwind CSS.

Acoes realizadas:

- Instalado e ativado o plugin oficial `@tailwindcss/vite`
- Configurado `src/global.css` com `@import "tailwindcss"`
- Criados tokens iniciais de tema para as cores da EduMoz
- Aplicadas classes Tailwind nos componentes iniciais
- Ajustado `.gitignore` para ignorar a cache local usada na instalacao

Esta decisao torna o desenvolvimento visual mais rapido, consistente e facil de
manter durante as proximas fases da plataforma.

## 2026-05-24 - Navbar, acessibilidade e paginas basicas

Foi criada a primeira versao do navbar principal da EduMoz com foco em uso real
da plataforma.

Acoes realizadas:

- Navbar com nome da plataforma e links principais
- Botao para abrir modal de acessibilidade
- Opcoes iniciais de acessibilidade: contraste, texto maior, reducao de
  movimentos, modo leitura e foco visivel
- Menu responsivo para estado smartphone
- Circulo de utilizador com estado de login e suporte futuro para imagem de
  perfil
- Pagina basica de entrada em `/entrar`
- Pagina basica de solicitacao de acesso em `/solicitar-acesso`
- Pagina basica da area do aluno em `/aluno`

Observacao: os formularios e opcoes de acessibilidade ainda sao visuais nesta
fase. A ligacao com backend, preferencias reais do utilizador e autenticacao
ficara para uma etapa posterior.

## 2026-05-24 - Revisao do clique de acessibilidade no navbar

Foi revista a acao do botao de acessibilidade no navbar e removida a duplicacao
de estados que existia entre a primeira versao do modal e os novos componentes.

Acoes realizadas:

- Navbar passou a usar um unico estado para abrir e fechar o modal de
  acessibilidade
- Botao de acessibilidade ficou visivel no desktop
- Botao de acessibilidade foi adicionado dentro da navlist mobile
- Ao clicar em acessibilidade no mobile, o menu fecha e o modal abre
- Preferencias de acessibilidade passaram a ser guardadas no `localStorage`
  usando chave da EduMoz
- Foram criadas classes globais para contraste, tamanho de texto, fonte legivel
  e reducao de movimentos
- Links do navbar foram centralizados em `src/data/links.ts`
- Foram ajustados componentes auxiliares do navbar: `MobileMenu`, `NavLink` e
  `UserAvatar`

Observacao: nesta fase as preferencias ja alteram a experiencia visual basica,
mas ainda podem ser refinadas com mais modos, icones e persistencia ligada ao
perfil do utilizador quando houver autenticacao real.

## Vercel Edge

This starter site is configured to deploy to [Vercel Edge Functions](https://vercel.com/docs/concepts/functions/edge-functions), which means it will be rendered at an edge location near to your users.

## Installation

The adaptor will add a new `vite.config.ts` within the `adapters/` directory, and a new entry file will be created, such as:

```
└── adapters/
    └── vercel-edge/
        └── vite.config.ts
└── src/
    └── entry.vercel-edge.tsx
```

Additionally, within the `package.json`, the `build.server` script will be updated with the Vercel Edge build.

## Production build

To build the application for production, use the `build` command, this command will automatically run `npm run build.server` and `npm run build.client`:

```shell
npm run build
```

[Read the full guide here](https://github.com/QwikDev/qwik/blob/main/starters/adapters/vercel-edge/README.md)

## Dev deploy

To deploy the application for development:

```shell
npm run deploy
```

Notice that you might need a [Vercel account](https://docs.Vercel.com/get-started/) in order to complete this step!

## Production deploy

The project is ready to be deployed to Vercel. However, you will need to create a git repository and push the code to it.

You can [deploy your site to Vercel](https://vercel.com/docs/concepts/deployments/overview) either via a Git provider integration or through the Vercel CLI.
